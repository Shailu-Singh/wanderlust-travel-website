
# 🌍 Wanderlust - Travel Website

A travel website built using HTML and CSS to showcase beautiful destinations.

## 🔗 Live Demo

[Visit Website](https://shailu-singh.github.io/wanderlust-travel-website/)

## ✨ Features

- Attractive navigation bar
- Hero section with background image
- Destination cards with images and descriptions
- About Us section
- Contact form UI
- Responsive design for mobile screens
- Hover effects and smooth scrolling

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Media Queries

## 📍 Destinations

- Mathura & Vrindavan, Uttar Pradesh
- Varanasi, Uttar Pradesh
- Haridwar, Uttarakhand

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
